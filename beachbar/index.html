⛱️ Beach Bar — ordering prototype

Guests scan the QR code on their umbrella, order from the sunbed, pay with a stored card and get the receipt by e-mail. The bar sees every ticket live. Everything runs offline in the browser — no server, no real payments.

Guest app (blue) Menu, options, cart, payment, order tracking, music requests. Add to home screen → blue icon. Bar station (red) Live tickets, preparation, delivery, manual orders, music. Add to home screen → red icon. Dashboard Revenue, orders, top products, prep times, umbrella map, CSV export. QR codes Printable labels, one numbered code per umbrella.

Try the whole flow

  1. Open QR codes, set the base URL to the address your phone can reach, print or scan from the screen.
  2. Scan umbrella 12 → the guest app opens for that umbrella.
  3. Order a Freddo Espresso with little sugar, pay with the stored card, request a song.
  4. Open the bar station in a second window — the ticket is already there.
  5. Accept → ready → delivered; the guest sees each step live.
  6. Check the dashboard for revenue, top products and open tabs.

Prototype — no real payment is processed, invoices are simulated.
